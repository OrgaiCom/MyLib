# MyLib - 汎用ユーティリティライブラリ

このリポジトリは、様々な用途に利用できる汎用的なユーティリティクラス群を提供するライブラリです。診断、数学、CSV処理、データ操作、ファイル操作、ロギング、OS情報取得、乱数生成、文字列操作、時間関連機能など、多岐にわたる機能を含んでいます。

## 主な機能

- **LibDiag.cs**: 診断関連のユーティリティ
- **LibMath.cs**: 数学的な計算ユーティリティ
- **LibCsv.cs**: CSVファイルの読み書き処理
- **LibData.cs**: データ構造やデータ操作関連のユーティリティ
- **LibFile.cs**: ファイルシステム操作のユーティリティ
- **LibLog.cs**: ロギング機能
- **LibOs.cs**: オペレーティングシステム関連の情報取得
- **LibRandom.cs**: 乱数生成機能
- **LibStr.cs**: 文字列操作ユーティリティ
- **LibTime.cs**: 日付と時刻関連のユーティリティ
